# Channel name ideas

The topic list (fly fishing, trucks, Bermuda lawns, grilling, football, beer, dogs, raising a boy, Java)
is "practical know-how from a regular guy." The name should fit that, stay broad while we test topics,
and still work if one niche takes off.

## Top picks

| Name | Handle idea | Why |
|---|---|---|
| **Porch Talk** | @PorchTalkShorts | Casual and friendly, with a hint of Texas. Fits beer, sports, dogs, parenting and lawn tips without sounding like a "tips channel." **Recommended.** |
| **Weekend Know-How** | @WeekendKnowHow | Says exactly what the value is: things you use on Saturday. Great for lawns, trucks, grilling and fishing. |
| **Tailgate Talk** | @TailgateTalkTips | Fun and sporty, and fits beer, football and grilling. Slightly weaker for coding or parenting. |
| **Dad Knows Stuff** | @DadKnowsStuff | Strong personality, fits parenting, trucks, lawn and grill. Sets the expectation that it's dad-focused. |

## Also good

## Tips

- Check that the handle is free on YouTube before deciding, and also on TikTok and Instagram if you want to cross-post later.
- Avoid a niche word in the name during exploration ("Fishing ...", "Lawn ...") because it boxes you in.
- You can rename later: YouTube allows changing the channel name and handle. Handles can be changed twice every 14 days.
- Set `FYA_CHANNEL_NAME` in GitHub variables to whatever you choose. It's shown on each video and given to the scriptwriter.
