# Channel name ideas

The topic list (fly fishing, trucks, Bermuda lawns, grilling, football, beer, dogs, raising a boy, Java,
phone and computer tips) is "practical know-how from a regular guy." Every Short is published in English
and Spanish, ideally on two channels, so the brand should work as a pair.

## Recommended: Porch Talk / Plática de Porche

| | English | Spanish |
|---|---|---|
| Name | **Porch Talk** | **Plática de Porche** |
| Handle idea | @PorchTalkShorts | @PlaticaDePorche |

The porch is where you talk about anything: the truck, the lawn, the game, the new phone. That's why it
still fits now that tech is in the mix. "Plática" is the everyday Mexican and Texan word for a chat, so the
Spanish name sounds natural to the audience you'll most likely reach first.

## If you want one name that works in both languages

| English | Spanish | Why |
|---|---|---|
| **Patio Talk** | **Plática de Patio** | "Patio" is the same word in both languages, so the two channels read as one brand. Fits grilling, lawn and beer especially well. |
| **Tip Rápido** | **Tip Rápido** | One name for both. "Tip" is used in Spanish, and English speakers get "rápido." Very clear about the format. A bit generic. |
| **Saber Más** | **Saber Más** | Short and memorable. Spanish-first, so it suits a channel pair that leans Spanish. |

## Other English options from before

- Weekend Know-How (doesn't translate well)
- Tailgate Talk (weaker fit for tech and parenting)
- Dad Knows Stuff ("Papá Sabe" in Spanish)

## Tips

- Check that both handles are free on YouTube before deciding, and also on TikTok and Instagram if you might cross-post.
- Avoid a niche word in the name during exploration ("Fishing ...", "Tech ...") because it boxes you in.
- You can rename later. Handles can be changed twice every 14 days.
- Set `FYA_CHANNEL_NAME` and `FYA_CHANNEL_NAME_ES` in GitHub variables. They're shown on each video and given to the scriptwriter.
