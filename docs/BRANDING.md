# Channel branding

Images are in `assets/branding/`. They're generated by `node branding/render.js`, so colors and text can be
changed in that file and re-rendered.

| File | Use | Size |
|---|---|---|
| `profile-en.png` | Porch Talk Pro profile picture | 800x800 |
| `profile-es.png` | Plática de Porche profile picture | 800x800 |
| `banner-en.png` | Porch Talk Pro banner | 2560x1440 |
| `banner-es.png` | Plática de Porche banner | 2560x1440 |

The logo is a porch roof over a speech bubble. It has no words, so it works in both languages. The English
channel is dark slate and the Spanish channel is terracotta, so viewers can tell them apart. The gold matches the
caption highlight in the videos.

## Where to upload

YouTube Studio, on each channel (profile picture → Switch account to change channels):

1. **Customization → Branding**
   - **Picture → Upload**: `profile-xx.png`. Keep the default crop.
   - **Banner image → Upload**: `banner-xx.png`. Keep the default crop; the text sits in the area every device shows.
   - **Video watermark**: skip (it isn't shown on Shorts).
2. **Customization → Basic info**
   - **Description**: paste the text below.
   - **Links → Add link**: link each channel to the other (titles below).
3. Click **Publish** (top right).
4. **Settings → Channel → Basic info → Keywords**: paste the keywords below.
