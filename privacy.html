Privacy Policy

Porch Talk Uploader · Effective November 9, 2026

Porch Talk Uploader ("the tool") is a private publishing tool operated by the owner of the Porch Talk Pro and Plática de Porche YouTube channels. This policy explains what the tool does with Google and YouTube data.

YouTube API Services

The tool uses YouTube API Services to upload videos. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Who uses the tool

Only the channel owner. The tool isn't offered to the public, and no other person can sign in to it.

What data the tool accesses

  • It asks Google for one permission: upload videos to YouTube (the youtube.upload scope), for the owner's two channels only.
  • It uses that permission to upload the owner's own videos, with their titles, descriptions, tags and privacy settings.
  • It doesn't read, collect or analyze viewers' data, comments, subscribers or any other user's information.

What is stored, and where

  • The authorization token Google issues is stored as an encrypted secret in the owner's GitHub repository settings, and is used only to upload videos.
  • A log of the videos the tool made (date, topic, title, and the YouTube video ID) is kept in the tool's repository.

Sharing

Data obtained through YouTube API Services isn't sold, shared with third parties, or used for advertising.

Revoking access and deleting data

The channel owner can revoke the tool's access at any time from the Google Account permissions page (also reachable via Google security settings). Revoking access makes the stored token useless; the owner can then also delete it from the repository's secrets. The video log can be deleted from the repository at any time.

Changes

If this policy changes, the updated version will be posted on this page with a new effective date.

Contact

Questions about this policy: open an issue on GitHub.
